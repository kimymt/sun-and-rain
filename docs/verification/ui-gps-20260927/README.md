# 画面圧縮・手動更新制限・GPS周辺候補

公開先: https://sun-and-rain.kei1127miyamoto.workers.dev/ 。配信Version ID: `269f2dfc-8953-4519-b57d-0545cd3bdf7d`、SW版: `d8fe90c5710de396`。

## 変更

- ヘッダーを44pxへ圧縮し「雨と日差しの予報」に変更。大きな地点見出し、期間表示、座標表示、実データ版バッジを削除。
- 選択地名を「地点を変更」の隣に配置。取得・保存の状況はホーム画面案内より後、フッター直前に移動。
- 変更なしの文言案として「前回見た予報から、大きな変化はありません。」を採用。初回は「次回から、今回の予報との変化を表示します。」、比較不能は「前回の予報と比較できるデータがありません。」。一部比較不能の場合は補足を維持。
- 手動更新は押した時点から60分間停止。失敗した場合も同じ制限。次回可能時刻を表示。地点を変えても制限を解除しない。
- IndexedDBで更新期限の確認・予約を同一トランザクションにし、再読込・別タブ・同時操作に対応。BroadcastChannelで開いている画面にも反映。保存不能時は画面内だけの制限へ移行し、保存できないことを表示。
- 初回・再読込・地点変更時の取得と30分の自動更新は従来どおり。これは手動ボタンの制限であり、API全体の1時間上限や課金制限ではない。

## 周辺候補

ユーザーの選択に従い「現在地周辺の地名候補」を実装。名前付きの自宅・勤務地保存は追加していない。

- ボタン操作時にブラウザの位置情報を1回取得。高精度を要求、キャッシュ許容60秒、位置取得タイムアウト10秒。GPS以外の測位方式になる場合もある。
- Geolonia住所データv2の市区町村代表点1,898件を抽出して同梱（102,951 bytes）。元データのmeta.updatedは1735102668（2024年12月）。取得日は2026-09-27であり、データ更新日とは区別。
- 球面距離で50km以内、近い順の最大5件。推定位置誤差と代表点までの距離を表示。行政界への所属判定や自宅・職場の住所特定ではない。候補の代表点と現在地は異なる。
- 座標を外部の地名APIへ送らず端末内で検索。GPS座標自体は保存しない。確定した代表点と地名は既存形式で端末保存し、代表座標をOpen-Meteoへ送る。
- 許可拒否、取得不能、タイムアウト、50km以内に候補なし、範囲外、データ取得失敗は文字列検索へ誘導。キャンセル後の遅いGPS応答は破棄。
- Permissions-Policyのgeolocationをselfへ変更。外部通信先を追加せず、候補データもPWAキャッシュに含める。GPS測位自体のオフライン利用可能性は端末に依存。
- CC BY 4.0、作成者・元データ・抽出加工をダイアログとデータ内に明記。[取得元とハッシュ](city-data-source.json)。
