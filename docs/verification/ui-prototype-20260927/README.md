## 結果

詳細は [results.json](results.json)。Chromiumの320・390・768・1280px幅、それぞれ5シナリオの計20組でPASS。

- 前後ボタン、スライダーのHome／End／矢印キー、グラフのクリック／タップによる時間選択。
- 選択範囲両端でのボタン無効化と、一部時間区間の説明。
- 欠損、翌日への移行、古い保存予報の注意表示。
- 指標説明と13区間の数値一覧の展開。
- ページの横方向のはみ出しがないこと。CSSの基準文字サイズ200%でも同項目を確認。
- JavaScriptのページ例外なし。

画面画像を確認し、欠損を線でつながないこと、変更区間の表示、スマートフォンで5指標を縦に並べる構成、デスクトップでの左右配置を確認した。

### 修正履歴

最初のテストはグラフ左端から10pxを10–11時と仮定し、320px幅で11–12時が選択されて失敗した。表示の開始が10:35で、最初の区間は25分だけなので、テストの座標指定が誤っていた。12:30に対応する座標を時間軸から計算し、12–13時が選択されることを検証するよう修正した。

画像確認後、夜間・欠損の凡例を追加した。意味の説明がないUVの補助線を削除し、古い予報の比較元時刻が取得時刻より後になる固定表示も修正した。変更後に全20組を再実行した。
