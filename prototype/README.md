# 12時間予報のUI試作品

2026-09-27。架空データによるメイン画面の検証用。実際の天気には使えません。

## 開き方

このディレクトリの `index.html` をブラウザで開きます。HTML・CSS・JavaScriptの3ファイルを同じディレクトリに置いてください。ビルドや依存ライブラリのインストールは不要です。

## 確認できること

- 12時間を共通の時間軸で表示。降水確率・降水量・日照・UV・気温を上下に並べる。
- グラフのタップ、前後ボタン、スライダーで時間を選択し、数値を確認する。
- 前回から変わった区間と変更前後の値を表示する。
- 午後から雨／日照が続く／夜から朝／一部欠損／古い保存予報の5例を切り替える。
- 夜間は背景色、欠損は斜線、変更は破線で区別する。
- 数値の読み方と時間別のテキスト一覧を開く。

## 表示上の判断

スマートフォンでは傾向を先に、選択時間の数値を下に置く。12個のカードを横スクロールする構成は採用しない。画面幅がある場合は数値を右に並べる。

10:35から22:35の12時間には、10–11時と22–23時の一部を含む13区間が重なる。両端だけを描画範囲で切り、1時間の値を残り時間へ比例配分しない。気温は正時、降水量・日照・UVは区間値として区別する。降水確率の時間補間について説明を置く。

日照は1時間当たりの分数、UVは1時間平均として表示する。単位・時刻の契約は [WEATHER_DATA_CONTRACT.md](../WEATHER_DATA_CONTRACT.md) を参照。気象情報の参照先は [Open-Meteo公式資料](https://open-meteo.com/en/docs)（2026-09-27到達確認）。

## この段階の制約

予報変更は固定した表示例であり、差分判定エンジンではない。夜間は架空例の18–6時固定。天気・湿度・風速も表示例用の仮値である。本実装で天気を日照や降水量から推測する仕様にはしない。APIの時刻変換、地点設定、取得処理、永続化、Service Worker、インストール対応は未実装。

## 次に確認すること

実際のiPhoneで、各表示例を5秒見て「雨が増える時間帯」「日差しがある時間帯」「UVが高い時間帯」「気温が上がるか下がるか」を読み取れるか確認する。続いて16–17時の数値と変更前の値を探す。正答と所要時間を記録する。結果に応じて画面の密度とグラフの高さを調整する。
